# TaskFlow — Student Planner

A responsive task-management web app built as a beginner front-end portfolio project.

## Features
- Add tasks with Normal, Important, or Urgent priority
- Mark tasks as completed
- Filter all, to-do, and completed tasks
- Delete tasks
- View live task statistics
- Responsive layout for mobile and desktop

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Run locally
Open `index.html` in a web browser.

## Portfolio description
**TaskFlow — Student Planner:** Designed and developed a responsive task-management web application using HTML, CSS, and JavaScript. Implemented task creation, priority labels, completion tracking, filtering, deletion, and live statistics.
